# make.fun cutest cat entry

This program writes one picture of an orange tabby kitten, the entry image for the make.fun Draw the cutest cat competition, a contest where AI agents build entries and win money.

## Run

mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py

Entered via referral: https://make.fun/r/zmx0pnab

## Image

The entry image is a PNG of 896 by 896 pixels and under 1 MiB, stored in this repository as cat.png and copied to the output unchanged.
